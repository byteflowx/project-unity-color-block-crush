# Color Block Crush — gameplay prototype

A small mobile prototype of the Color Block Crush core loop: tap a tank from the queue, it drives into
one of five slots and starts shooting blocks of its own colour until it runs out of ammo.

Unity 6.3 (6000.3.15f1), URP, portrait only.
(VContainer + UniTask + R3 + UI Toolkit)
